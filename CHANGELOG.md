## [0.1.0]

The first version.

- Command-Tab shows a panel of Retab's own: one icon per app, and one per browser profile.
- Chrome profiles carry the account's picture and the profile's colour, read from Chrome's own settings.
- Needs Accessibility only; never looks at the screen and does not ask for Screen Recording.
- A title and subtitle above the icons say where the selected one leads: window, account, number of windows, state and desktop.
- Dock badges on the icons; what is playing, for Music and Spotify.
- Uses the shortcut the Mac already has for switching apps, and falls back to Option-Tab if the system does not hand it over.
- No keyboard listening: only system-registered shortcuts.
